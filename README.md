## 常见问题

**25.92 元是一年的价格吗？**
不是。25.92 元是起步价，对应 3 个月、6 个月、1 年三档折扣，下单时选时长后看结算页实付金额。比价先折算到年。

**没有学生证能买吗？**
25 周岁以下完成学生认证可免学生证；超过 25 周岁要按页面要求提交学籍信息，审核通过才有购买资格。

**校园计划和个人首单 38 元能同时买吗？**
可以。校园服务器限购 1 台，个人首单秒杀限 1 个，两条优惠线独立。

**学生机续费多少钱？**
校园服务器没有公开的续费同价承诺，按控制台当时价格续费；部分特惠档标注续费同价限 1 次。校园云数据库有 3 次优惠续费资格。

**2核2G 够用吗？**
个人博客、课程项目、单个 Web 服务够用。要同时跑数据库和多个 Docker 容器，选 2核4G，带宽和流量也更大。
